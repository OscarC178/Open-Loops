Preferenceswhich AI and model · daily refresh time

 

  
Your AI

  
Which AI assistant reads your messages and writes the nudges. It must be installed and signed in on this computer — after switching, the Home tab re-checks the connections.

  
  

   
   
   
Claude only. Which Claude model the scans, refreshes and chase drafts run on, and how hard it thinks per turn. Sonnet at high or Opus at medium both do the job; Sonnet is the cheaper of the two. "Claude Code's default" uses whatever claude is set to on this computer, which is often the most expensive model.

  

  
Before you schedule a daily refresh: Codex runs on your ChatGPT plan, which only allows so much Codex use every 5 hours and every week, shared with ChatGPT's other Codex tools. Every scan, refresh and chase uses some of it. If it runs out, Open Loops can't read anything until it comes back. Gmail and Slack are the ones connected in your ChatGPT account (chatgpt.com/apps), and Miro isn't available with Codex.

  

  

   
   
Grok only. Off (default) = Gmail-only; Slack is not started or checked. On = load Grok's Slack plugin and show it on the connection checklist — then Open Grok → /mcps → Slack → i.

  

 

 

  
Daily refresh time

  
Weekdays, only while you're logged in. Runs the refresh, then the timer (if enabled). Pick something before you'd normally open the page. Applies on its own; no need to press Save.

  

     
  

 

 

 
Historyhow far back it reads · what it writes to disk

 

  
History

  
How far back the AI reads when building context — the "who's who" people scan (both people you write to and real people who write to you), and the very first loop scan. Longer = fuller picture, slower scans. To re-scan with a new window: press "Pick from who I message most" below, or Start over for a full rebuild.

  
 

 

  
What Open Loops writes to disk

  
Everything lives next to the app, nothing else on this computer is touched: state.json (your list), state/logs/ (one log per job run), state/daylog/<date>.json + .html (each Day log), state/roadmap.json and state/roadmap-created.txt (Miro cards it added), and your own to-do file if you set one under Connections.

Connectionsyour own to-do file · Miro roadmap board

 

  
Your own to-do file (optional)

  
A markdown file you already keep, anywhere on this computer (a notes vault, a synced folder, a git repo). Its open lines show under Needs me; pressing done asks how you closed the item and writes that back into the file. Re-read about once a minute. Leave blank if you don't keep one.

  
  

  
The file format
   
One item per line, ids A1, A2… Snooze an item by adding | snoozed-until YYYY-MM-DD. Tick it here or in Open Loops.

   
- [ ] A1 | project | what to do | added 2026-09-15
- [ ] A2 | Client X | send the revised quote | added 2026-09-15 | snoozed-until 2026-09-22
- [x] A3 | project | done item | added 2026-09-01 | done 2026-09-14

   
When you press done, the line moves under ## Closed and your note is appended under ## Closure notes as - A1 | date | note.

  

 

 

  
Roadmap (Miro)

  
The Roadmap section on Home adds cards to a frame on a Miro board. Board = its name or link; frame = the title of the roadmap frame on it. Needs Miro connected in Claude — the connection checklist on Home says how.

  
  
 

 

 
Appquit · start over

 

  
Quit

  
Closing this tab stops the app by itself a few seconds later (after any running job). This button does the same without closing the tab. To start again, double-click the Open Loops icon.

  
 

 

  
Start over

  
Wipes the list, the people picks and the learned tone, and takes you back to step 1 as a brand-new user would see it. Keeps your name, domains and tone settings. Slack/Gmail stay connected. This cannot be undone.
